# Floaty

<img src="res/icon-preview.png" alt="" width="360">

**תמונות שצפות מעל כל החלונות ב-Windows.** לוגו, חותמת או סימן מים, בכל מסך,
עם שליטה מלאה על גודל, מיקום, שקיפות וצבע. קובץ `.exe` אחד, בלי התקנה.

&rlm;Floaty הוא גרסה מורחבת של [Overlay Manager](https://github.com/tsoolgee/overlay-manager-win)
מאת tsoolgee. הבסיס, הרעיון ורוב הקוד שלו; ראו [קרדיט](#קרדיט) למטה.

---

## מה זה עושה

- **שכבות בלי הגבלה.** כל שכבה היא תמונה עם הגדרות משלה: PNG, JPG, BMP, GIF ו-WebP.
- **בכל מסך.** המיקום נשמר באחוזים מהמסך, ולכן הוא נשאר נכון גם אחרי החלפת רזולוציה.
- **מיקום בגרירה על המסך.** מזיזים ומשנים גודל ישירות, עם "שמור" או "ביטול".
- **מראה.** אטימות, סיבוב, שחור-לבן, צביעה בגוון והסרה של רקע אחיד.
- **לחיצות עוברות דרך השכבה.** היא לא חוסמת את מה שמתחתיה.
- **קיצור מקלדת גלובלי.** `Ctrl+Alt+H` מסתיר ומציג הכול מכל מקום, למשל לפני צילום מסך.
- **סמל ליד השעון, הפעלה עם Windows, ערכה כהה ובהירה, ושמירה אוטומטית.**
- **עדכון מתוך התוכנה.** הגרסה החדשה נבדקת מול SHA-256 לפני שהיא מוחלפת, ואחרי
  ההפעלה מחדש התוכנה אומרת מה חדש. אפשר לבחור גם רק לקבל הודעה.

## התקנה

מורידים את `Floaty.exe` מ-[Releases](../../releases) ומריצים. זהו.

**דרישה יחידה:** רכיב **WebView2** של מיקרוסופט. הוא מותקן בכל Windows 11 ובגרסאות
עדכניות של Windows 10. אם הוא חסר, התוכנה אומרת זאת ומציעה לפתוח את דף ההורדה.

**עוברים מ-Overlay Manager?** בהפעלה הראשונה Floaty מעתיק את ההגדרות והשכבות שלו.
ההגדרות של Overlay Manager עצמו לא משתנות.

ההגדרות נשמרות ב-`%APPDATA%\Floaty`. להסרה מלאה מוחקים את התיקייה הזו ואת הערך
`Floaty` תחת `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`.

## מה נוסף לעומת Overlay Manager 3.2.0

**תיקונים**
- החלון הנסתר של התוכנה לא קיבל הודעות מערכת. לכן שינוי מסכים לא טופל, השמירה
  בכיבוי המחשב לא קרתה, והסמל ליד השעון נעלם אחרי הפעלה מחדש של Explorer.
- ניתוק מסך העביר את השכבות שלו למסך הראשי לצמיתות.
- השכבה שנערכה אחרונה קפצה מעל כל השאר, בלי קשר לסדר ברשימה.
- קובץ התמונה ננעל כל עוד השכבה הוצגה, ואי אפשר היה לשמור עליו מעורך תמונות.
- שינוי גודל של שכבה מסובבת ניפח אותה בכל גרירה.
- מצב המיקום עבר לשכבה אחרת כשהוזזו או נמחקו שורות, ונשאר דלוק אחרי סגירת החלון.
- ההודעה "צירוף המקשים תפוס" לא הוצגה אף פעם.

**ממשק חדש**
- גודל החלון מותאם להגדלת מסך (125%, 150%). קודם, בגודל ברירת המחדל, שדות הגודל
  הציגו רק "px" והמחוונים התכווצו לנקודה.
- שדות עם תוויות ברורות, כפתורים עם מילים, וסידור שכבות גם בכפתורים ולא רק בגרירה.
- הרשימה מהעליונה אל התחתונה, כמו בתוכנות גרפיקה, ותצוגה מקדימה של כל השכבות על המסך.
- "ביטול" למצב המיקום (גם `Esc`), שמירה אוטומטית, ומחיקה עם אישור בעברית.
- שורת כותרת כהה בערכה הכהה.

**עדכונים**
- הודעה על גרסה חדשה גם כשההתקנה האוטומטית כבויה, ו"מה חדש" לפני ואחרי העדכון.
- זיהוי של עדכון שלא נכנס לתוקף, והסבר ברור כשגיטהאב מגביל בדיקות או כשאין הרשאת כתיבה.

## בנייה

</div>

```bash
nuget install Microsoft.Web.WebView2 -OutputDirectory packages -ExcludeVersion
cmake -S . -B build -A x64 -DWEBVIEW2_DIR="$PWD/packages/Microsoft.Web.WebView2"
cmake --build build --config Release
```

<div dir="rtl">

דרוש MSVC (Visual Studio 2019 ומעלה) ו-CMake 3.21+. הבנייה משתמשת ב-CRT סטטי
וב-`WebView2LoaderStatic.lib`, ולכן התוצר הוא קובץ אחד בלי DLL נלווה.
כל דחיפה ל-`main` נבנית ב-GitHub Actions.

## מבנה הקוד

| קובץ | תפקיד |
|---|---|
| `src/main.cpp` | נקודת כניסה, מודעות ל-DPI, אתחול COM |
| `src/app.cpp` | לב התוכנה: מגש, מקש קיצור, מופע יחיד, הודעות מערכת, פרוטוקול הגשר |
| `src/overlay.cpp` | חלונות השכבות: `UpdateLayeredWindow` + GDI+ |
| `src/manager.cpp` | חלון הניהול שמארח את WebView2 |
| `src/updater.cpp` | בדיקה, הורדה, אימות והחלפה של גרסה חדשה |
| `src/config.cpp` | קריאה וכתיבה של `config.ini` |
| `src/json.cpp` | מנתח JSON זעיר לגשר, בלי תלויות |
| `ui/index.html` | **כל הממשק**, מוטמע ב-EXE כמשאב `RCDATA` |

הגשר בין ה-HTML ל-C++ הוא הודעות JSON לשני הכיוונים
(`postMessage` / `PostWebMessageAsJson`). הדף לא ניגש לקבצים ולא לרשת: בחירת
תמונה וצבע נעשות בדיאלוגים של Windows, וכל שינוי נשלח לצד ה-C++ שמצייר מחדש.
